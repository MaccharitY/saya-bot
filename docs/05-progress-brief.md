## 2. 顺手修掉的真 bug（都是真机撞出来的）

1. **偶发的 `ConnectionAbortedError`** —— 拒绝请求时没读请求体就关连接，
   Windows 会发 RST。**约 4 次错 1 次**，我一开始以为是环境噪声想放过它。
2. **MCP SDK 2.x 把 `FastMCP` 改名成 `MCPServer`** —— v1 写法直接炸。
3. **图片缓存按 URL 后缀命名，YOLO 拒读**（QQ 链接没有可用后缀）。
4. **MCP 客户端吞掉了子进程的 stderr** —— server 起不来时毫无线索。
5. **实验执行器压根没读 `.env`**（传了 `None` 不读文件）——
   报错会说"未配置 API key"，但配置就摆在文件里，会把人引向完全错误的方向。
6. **`.sh` 会被检出成 CRLF** —— bash 报 `command not found`，脚本在新机器上直接跑不起来。

**课程截止 2026-10-29，报告需要真实对照数据。所以关键路径不是"把机器人做完整"，而是"尽早产出三条视觉路线的对照数据"。**

```
   今天        10-17       10-21        10-23              10-28  10-29
    │            │           │            │                  │     │
    ├─ 地基 ─────┤           │            │                  │     │
    │            ├─ 真QQ接入 ┤            │                  │     │
    │            │  ├─ 内核 ─┤            │                  │     │
    │            │           ├─ 三路线 ───┤                  │     │
    │            │           │    对照实验┤                  │     │
    │            │           │            ├─ 报告 & slides ──┤     │
    │            │           │            │                  ├ 发送│
    └ 之后：记忆 / 萌娘百科 / GitHub 公开 ──────────────────────────→
```

**推论（很重要）**：
- FR-7 记忆、FR-6 萌娘百科 → **不是关键路径**，课程截止前不做也不影响交作业。别让它们抢时间。
- FR-9 三路线 + FR-8 埋点 → **是关键路径**，必须最早做。
- 功能要**按"能不能产出数据"裁剪**，不是按"好不好玩"裁剪。
- ⚠️ **真 QQ 接入有封号风险**（ADR-008）。它在前关键路径上，但**内核开发不依赖它**——Mock 夹具保证 QQ 侧挂了也能继续。

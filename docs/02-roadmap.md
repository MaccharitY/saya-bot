## 0. 关键路径（先看这个）

**机器人是主项目；presentation 是附加交付物，靠机器人的实测数据来写。**

课程截止 2026-10-29 是一个**固定的外部约束**。它不改变主项目是什么，只决定**顺序**：先把"能产出对照数据"的部分做完（报告要用），再回到机器人的其余功能。

**⚠️ 记忆、萌娘百科这些是主项目功能，不是"可以不做"**，只是排在后面（M6）。不要用"交作业够了"当理由砍掉它们。

- FR-7 记忆、FR-6 萌娘百科 → **主项目功能，必须做**；顺序排在"能出数据"的部分之后（M6），不是因为不重要。

- ⚠️ 真 QQ 接入有封号风险。**内核开发不依赖它**——Mock 夹具保证 QQ 侧挂了也能继续。

**实测数据（报告要用）**：

| | 输入 tokens | 延迟 |
|---|---|---|
| 纯文字回复 | ~250 | 1.1~1.5 s（DNS 修好后） |
| **带一张图** | **594 / 1227** | 3.1~7.5 s |
| 本地 CV：detect 首次 | — | **17441 ms**（含模型下载 + CUDA 初始化） |
| 本地 CV：detect 热 | — | **31 ms** |

→ **一张图吃 350~1000 输入 token**；**本地推理冷热相差 560 倍** ——
报告里必须区分"冷启动"与"稳态"，否则延迟数字没有意义。
